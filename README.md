## 📖 프로젝트 소개 (About)

**Simple Sudoku**는 Java와 Android Studio를 사용하여 개발한 안드로이드 스도쿠 게임입니다.
사용자가 직관적인 인터페이스를 통해 스도쿠 퍼즐을 즐길 수 있도록 제작되었으며, 안드로이드 앱 개발의 기초적인 생명주기와 UI 구성을 학습하고 실습하기 위해 만들어졌습니다.

## ✨ 주요 기능 (Key Features)

* **스도쿠 게임 플레이**: 9x9 그리드에서 표준 스도쿠 룰에 따른 게임 진행
* **직관적인 UI**: 숫자 입력 및 게임 조작이 간편한 사용자 인터페이스
* **문제 생성 및 검증**: 랜덤 퍼즐 생성 및 정답 확인
* **오답 체크**: 잘못된 숫자 입력 시 시각적 알림

## 🚀 설치 및 실행 방법 (Getting Started)

이 프로젝트를 로컬 환경에서 실행하려면 다음 단계가 필요합니다.

1. **프로젝트 클론 (Clone)**
   ```bash
   git clone [https://github.com/Shiny-Shine/Sudoku.git](https://github.com/Shiny-Shine/Sudoku.git)
2. **Android Studio에서 열기**
  * Android Studio 실행 -> Open -> 클론한 Sudoku 폴더 선택
3. **프로젝트 빌드 및 실행**
  * Gradle Sync가 완료될 때까지 대기
  * 에뮬레이터 또는 실제 기기를 연결하고 Run (Shift + F10) 버튼 클릭
